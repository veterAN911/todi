# Как участвовать в проекте

Спасибо за интерес к Todi. Ниже — короткие правила, которые помогут принять
изменение без лишних кругов.

## Сообщения об ошибках

В issue приложите:

- версию приложения и версию Android;
- модель устройства и прошивку, если ошибка связана с уведомлениями или
  экраном блокировки;
- шаги, после которых ошибка воспроизводится;
- ожидаемое и фактическое поведение;
- `adb logcat` с фильтром по тегам `CalendarSync` или имени пакета, если ошибка
  видна в логах.

Не прикладывайте содержимое дел, адреса электронной почты и коды из писем.
Если для воспроизведения нужен текст, замените его вымышленным.

## Предложения изменений

1. Создайте issue с описанием задачи, если её ещё нет.
2. Сделайте fork и отдельную ветку от `main`.
3. Внесите изменение и добавьте тесты.
4. Убедитесь, что проходят `make verify` и, если затронут UI,
   `make ui-test` на эмуляторе.
5. Откройте pull request с описанием того, что и зачем изменено.

Не смешивайте в одном pull request разные по смыслу изменения: форматирование,
переименования и новую функциональность лучше разделять.

## Стиль кода

- Публичные и внутренние API, сообщения коммитов и документация — на русском или
  английском, но последовательно в пределах одного изменения.
- Форматирование задаёт `ktlint` с профилем `ktlint_official`; запускайте
  `make ktlint-format` перед коммитом.
- Пользовательские строки живут только в `res/values/strings.xml` и
  `res/values-en/strings.xml`.
- Визуальный слой не читает часы и не вычисляет даты; решение принимает
  ViewModel или чистая функция из `domain/util`.
- Все списки обязаны исключать удалённые дела (`deletedAt == null`) и, где это
  применимо, дела без даты (`isGlobal = 0`).
- Содержимое дел, адреса почты и токены не логируются.

## Тесты

- Чистая логика — юнит-тестами в `app/src/test`.
- Работа с Room, уведомлениями и навигацией — инструментальными тестами в
  `app/src/androidTest`.
- Исправление ошибки сопровождается тестом, который без исправления падает.
- Тесты не должны зависеть от текущей даты: день передаётся параметром.

## Коммиты

Сообщение в повелительном наклонении, коротко о сути:

```
Fix duplicate task when editor saves a date-less item
Add contrast check to notification palette
```
