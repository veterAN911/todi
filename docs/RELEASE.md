# Релиз

## Версия

Версия задаётся в `app/build.gradle.kts`:

```kotlin
versionCode = 2
versionName = "1.0.1"
```

`versionCode` обязан увеличиваться при каждой публикации в Google Play.
`versionName` — человекочитаемая версия; она показывается на экране
«О приложении» из `BuildConfig`, а не из строки ресурсов.

Поднять обе версии можно командой:

```bash
make bump-version
```

## Подпись

Release-подпись читается из `keystore.properties` в корне репозитория:

```properties
storeFile=release.keystore
storePassword=...
keyAlias=todi
keyPassword=...
```

Создание ключа и файла:

```bash
make init-keystore
```

`keystore.properties`, `*.jks` и `*.keystore` исключены из репозитория. Не
коммитьте их и не передавайте вместе с исходниками.

Проверка отпечатков:

```bash
make fingerprints
make fingerprints-release
```

Отпечаток SHA-256 понадобится при подключении сервисов и при обновлении
приложения.

## Сборка

```bash
make clean
make verify
make build-release
make bundle
make size
```

- `build-release` создаёт подписанный APK.
- `bundle` создаёт AAB для Google Play.
- `size` сравнивает release-APK с бюджетом 50 МБ.

Перед публикацией проверьте, что проходит `make verify`, а на устройстве —
основные сценарии: создание дела, уведомление, экран блокировки, напоминание,
поиск, архив и резервная копия.

## Публикация в Google Play

1. Соберите AAB командой `make bundle`.
2. Загрузите его в Google Play Console.
3. Убедитесь, что языки карточки совпадают с локалями AAB: в бандле объявлены
   только `ru` и `en` благодаря `localeFilters`.
4. Заполните описание, скриншоты и политику конфиденциальности.
5. Для приложений с аккаунтом Play требует удаление аккаунта изнутри приложения
   и публичную страницу удаления. Публичная страница должна работать без
   приложения.
6. Отправьте сборку на проверку.

Приложение использует разрешения:

- `POST_NOTIFICATIONS` — основное уведомление;
- `RECORD_AUDIO` — голосовой ввод;
- `READ_CALENDAR`, `WRITE_CALENDAR` — экспорт дел;
- `RECEIVE_BOOT_COMPLETED` — восстановление расписания после перезагрузки;
- `ACCESS_NETWORK_STATE` — сетевое ограничение WorkManager.

В манифесте должны быть обоснования для чувствительных разрешений, если этого
требует выбранная категория приложения.

## Тег и релиз на GitHub

```bash
git tag v1.0.1
git push origin v1.0.1
```

В релизе приложите:

- APK для прямой установки, если он подписан тем же ключом;
- список изменений из `CHANGELOG.md`;
- SHA-256 файлов.

## Чек-лист

- [ ] `make verify` проходит.
- [ ] `make ui-test` проходит на эмуляторе.
- [ ] `versionCode` увеличен.
- [ ] `CHANGELOG.md` обновлён.
- [ ] Уведомление показывается на экране блокировки.
- [ ] Голосовая модель скачивается и распознаёт речь.
- [ ] Резервная копия создаётся и восстанавливается.
- [ ] В логах нет содержимого дел.
- [ ] AAB не содержит лишних локалей.
